# 矩阵变换实验室 · Matrix Transformation Lab

对应线性代数教材第 2 章 2.5.1「平面图形变换」与 2.5.2「矩阵在计算机图形学中的应用——齐次坐标」。

## 启动

保留项目目录结构，在文件资源管理器中双击 `index.html`。默认打开二维图形变换实验室，通过顶部导航切换模块。网页使用本地 HTML、CSS、JavaScript 和 SVG，无需联网、安装依赖、构建或登录。

也可从项目目录启动供本机浏览器访问的静态预览：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

随后打开 `http://127.0.0.1:8765/index.html`，用 Ctrl+C 停止服务器。

## 功能与操作

| 模块 | 操作 |
| --- | --- |
| 齐次坐标 | 点击「转为齐次坐标」为二维点补上末分量 1。调节平移量，再点击三次「计算下一行」查看点积与最终位置。 |
| 变换实验室 | 选择三角形或正方形，再选平移、旋转、缩放或错切。拖动滑块查看蓝色原图、橙色结果、矩阵与顶点坐标。播放时，计算区显示当前帧。「重置」恢复三角形和平移恒等变换。 |
| 动态动画 | 选择平移、旋转、缩放或逐行计算。可播放、暂停、继续、重播和单步，支持 0.5× 至 2× 播放速度。逐行计算模式在三行都算完后绘制目标点。 |
| 组合变换 | 默认并排展示两种顺序的最终图形与矩阵乘积。用「播放」从初始状态连续演示，或用「单步」依次比较两次操作。勾选指定中心，调整 `cx`、`cy` 观察绕不同中心旋转。 |
| 知识检测 | 回答 5 道单选题后提交，查看总分、正确答案和题目解析。点击「重新答题」清空作答。 |

## 数学约定

- 点使用齐次列向量 `p = [x, y, 1]ᵀ`，通过 `p′ = M p` 左乘。旋转的正角为逆时针。
- 平移量在第三列。缩放允许负值和零，退化后仍绘制顶点并列出各顶点坐标。错切的两个输出分量都取自同一个原始点。
- 若先执行 `M1` 再执行 `M2`，总矩阵为 `M2 × M1`。默认组合算例把 `(1, 0)` 沿 x 轴平移 2，再逆时针转 90°，结果为 `(0, 3)`。交换顺序得到 `(2, 1)`。
- 绕中心 `C = (cx, cy)` 旋转使用 `T(C) × R × T(−C)`。组合页坐标滑块范围为 −3 至 3。
- 所有动画帧都用当前矩阵变换原始顶点。绘图通过 `matrix.js` 的统一映射将数学 y 轴翻转一次。界面数值最多显示三位小数，核心计算保留浮点精度。

## 文件职责

| 路径 | 职责 |
| --- | --- |
| `index.html`、`css/style.css` | 单页学习界面和响应式布局 |
| `js/matrix.js` | 原有矩阵运算、点变换和 SVG 坐标映射 |
| `js/transform.js` | 图形、变换参数、动画参数插值与绕指定中心旋转 |

| `js/app.js`、`js/quiz.js` | 页面交互、学习导航与作答评分 |

## 测试

在项目目录用 Node.js 18 或以上运行：

```powershell
node --test .\tests\math-tests.js .\tests\interaction-tests.js
```

浏览器复测可先在实验室使用三角形顶点 A = (1, 0)。将角度设为 +90° 与 −90°，预期分别得到 (0, 1) 与 (0, −1)。用负比例和零比例复核缩放，确认退化顶点仍可见。随后测试动画暂停、继续、重播和分步，复核组合页两种顺序的默认坐标，并在知识检测页验证全对、错一题和重答。

已通过本机 HTTP 浏览器预览验证五个导航入口、滑块和图形联动、两种旋转方向、退化缩放、动画控制、绕指定中心的组合变换及评分。浏览器日志未记录错误或警告。本地文件资源路径由 Node.js 测试覆盖，浏览器自动化未直接打开 `file://`。
